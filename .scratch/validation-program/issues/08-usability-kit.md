# 08: Usability kit with a scoring sheet

**What to build:** a scripted usability kit: eight representative checker outputs (four TAMPERED, two INCONCLUSIVE, two CLEAN with a note), each with the verdict first, one sentence of reason, the evidence, and the next step; an answer key for what happened and what a reader should do; and a scoring sheet that computes the share of correct interpretations and the time per output against the 80 percent target after one wording-fix round. The kit contains no real user data and no telemetry.

**Blocked by:** None (can start immediately).

**Status:** ready-for-agent

- [ ] The eight outputs cover the four-two-two split and each carries all four message parts
- [ ] The answer key scores an interpretation as correct or not without ambiguity
- [ ] The scoring sheet computes share correct and median time from fixture responses
- [ ] A wording revision round is recorded and the target is checked afterward
